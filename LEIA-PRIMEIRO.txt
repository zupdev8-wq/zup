ZUP! 2.1.0 — Neon Free + Render + perguntas e aulas por seed
20/10/2026

1) Extraia este ZIP em uma pasta NOVA, abra zup-main no VS Code.
2) Para iniciar o aplicativo no Expo Go:

   cd app
   npm install
   npx expo start --go -c

3) A infraestrutura de dados no Neon/Render NAO foi configurada remotamente.
   Leia antes docs/NEON-RENDER-E-CURADORIA.md.
   Para perguntas e explicacoes remotas funcionarem:
   - Criar projeto Neon Free.
   - Configurar DATABASE_URL pooled no ambiente do Render, sem expor segredos no app.
   - Deploy da API atualizada.
   - Publicar seeds APENAS apos curadoria.

4) ARQUIVOS RECEBIDOS:
   20.622 candidatas (16.915 perguntas de 4 opcoes + 3.707 de 5),
   mas todas estao como RASCUNHO e nenhuma foi publicada.
   Esta versao aceita 5 alternativas, inclusive clicando E e retomando quizzes.
   Scripts:
   - scripts/export-curadoria-xlsx.py (XLSX para CSV, exige openpyxl)
   - scripts/prepare-curadoria-seeds.cjs (aprovar -> seed por categoria)
   - scripts/publish-content-seed.cjs (conferir, publicar, listar, rollback)

5) SEEDS SAO DADOS, NAO CODIGO:
   perguntas, gabaritos, justificativas, explicacoes, Ler mais e bibliografia
   podem mudar sem nova build apos a primeira build que contem esta integracao.

6) VALIDACOES LOCAIS:
   118 testes do nucleo do aplicativo, 13 testes da API registrados na versao recebida.
   Nao houve deploy Render, banco real Neon nem teste fisico iOS.
   Instalacao da API pela internet expirou neste ambiente, logo antes de publicar
   execute npm install no API e valide endpoints/migracoes reais.

7) NENHUMA chave de banco, token administrativo ou dado de usuario esta neste ZIP.
   Veja o relatorio separado ZUP-AUDITORIA-ACERVO-E-COBERTURA.xlsx.
