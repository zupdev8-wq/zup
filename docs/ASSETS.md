# Arte incluída — ZUP! 1.6.0

- `src/components/Icon.tsx`: pictogramas vetoriais de interface.
- `src/components/CategoryArt.tsx`: ilustrações vetoriais usadas fora do feed fotográfico.
- `src/components/CreatureArt.tsx`: quatro mascotes originais, com quatro formas evolutivas cada.
- `src/photos.ts`: banco curado com mais de 90 fotos reais únicas, organizado por grandes áreas de conhecimento e com variação por card para reduzir repetição.
- `assets/icon.png`: ícone do app.
- `adaptive-icon.png`: primeiro plano Android.
- `splash.png`: carregamento.
- `docs/COMPANHEIROS.html`: prancha dos mascotes.

O feed usa fotografia real como elemento dominante. Microaula, Biblioteca e feed reutilizam a mesma seleção sem depender de desenhos grandes como imagem principal.

Antes da publicação final, validar disponibilidade, licença/atribuição e política de uso de cada fonte remota; para produção, é recomendável migrar as imagens aprovadas para armazenamento/CDN controlado pelo ZUP para ter cache, consistência e menos dependência externa.

Lumi, Jaci, Zavi e Nox são personagens originais. O projeto não usa personagens, nomes, sprites ou desenhos de franquias de terceiros.
