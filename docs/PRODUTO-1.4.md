# Produto — ZUP! 1.5

## Loop principal

**Descobrir -> entender -> responder -> ganhar -> arquivar -> revisar -> evoluir.**

O feed “Pra você” mistura assuntos para evitar uma experiência escolar rígida. Filtros no topo permitem mergulhar em Brasil, Geopolítica, ENEM, Concursos, Faculdade, Humanas, Exatas, Biológicas, entretenimento, livros, religiões e pensamento crítico.

## Não repetição

Questões respondidas deixam a rotação normal. Elas permanecem no histórico/biblioteca e só reaparecem de forma explícita no modo Revisão.

## Premium

Premium é validado pelo backend e custa R$ 9,99 por 30 dias. O pagamento pode ser iniciado por Pix ou cartão via Mercado Pago.

Recursos Premium atuais:

- Simulado Inteligente de 20/45/60 questões;
- plano gerado a partir de banca, órgão, cargo, cidade, curso ou matérias digitadas;
- explicação curta depois de cada resposta;
- Maratona de 10 questões;
- base para mapa de domínio/estatísticas avançadas.

Nenhum toggle local concede acesso Premium.
